# 이전 파일럿 보관

이 폴더는 v1 도입 전 양식·워크플로·운영 안내의 이력을 보존합니다. 현재 사용법은 [시작 안내](../START-HERE.md)를 따릅니다.

`workflows/pilot.yml`은 `.github/workflows/` 밖에 있어 자동 실행되지 않습니다. `PILOT_ACTIVE`와 `AUTO_ROUTING_ENABLED`는 계속 비활성으로 유지합니다. 이전 Discord 안내·수동 라우팅 명령·접수 기간은 v1에 적용하지 않습니다. 보관 문서의 상대 링크는 당시 위치를 기준으로 작성되어 현재 동작하지 않을 수 있습니다.
